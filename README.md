# ⚡ 第二種電気工事士 過去問サクサク道場 (令和8年度上期)

PDFの第二種電気工事士の過去問（令和8年度上期学科試験・全50問）を、スマートフォンで親指一本でサクサク解きながら楽しく完全マスターできるWebアプリケーションです。

---

## 📱 主な特徴と機能

### 1. 🚀 スマホ特化のサクサク学習
- **片手親指操作**: 大きなタップ領域の四肢択一ボタン（イ・ロ・ハ・ニ）
- **即時判定＆詳細解説**: タップした瞬間にピンポン正解音・正誤判定・詳しい解法ステップ・「⚡試験直前！重要暗記ポイント」を表示
- **図面＆写真の完全収録**: 回路図・材料写真・工具写真・器具写真のトリミング画像を各問題に最適配置（タップでピンチ拡大可能）
- **配線図（15頁）ワンタップビューア**: 問31〜50の配線図問題では、画面上部に「📄 配線図を開く」ボタンが常駐。平面図・分電盤図を高精細ズーム表示

### 2. 🔥 間違えた問題を効率的に復習する仕組み（弱点特訓）
- **要復習自動ストック**: 間違えた問題は自動で「要復習リスト」にプール
- **理解度ステータス管理**:
  - `未挑戦`: まだ解いていない問題
  - `要復習 🔥`: 過去に間違えた問題
  - `正解済 ✨`: 直近で正解した問題
  - `完全マスター 👑`: 2回以上連続正解で卒業
- **クリップ（★ブックマーク）機能**: 気になった問題をワンタップで保存
- **特訓フィルタ**: 「要復習のみ」「クリップした問題」「未マスター問題」を瞬時に切り替えて周回可能

### 3. ⏱️ 全問正答までに必要な残りのプレイ時間の見積もり
- **リアルタイム速度計測**: ユーザーの実際の解答ペース（1問あたりの平均秒数）をリアルタイムに算出
- **推計残り時間の常時表示**: ヘッダーおよび実績モーダルに「全問制覇まで推計：あと約 ○分 ○秒（未マスター ○/50問）」を表示
- **モチベーション向上**: 問題をサクサク解いてマスターしていくと、残り時間がリアルタイムにグングン減っていきます！

### 4. 🎮 充実のゲーミフィケーション機能
- **レベル＆称号システム**:
  - 正解ごとに +100〜150 EXP 獲得
  - 称号ランク:
    - Lv.1〜4: 電工たまご 🐣
    - Lv.5〜9: 駆け出し電気工 🛠️
    - Lv.10〜19: 一人前電工 ⚡
    - Lv.20〜34: 敏腕スペシャリスト 🔥
    - Lv.35〜49: 電気工事マイスター 🏆
    - Lv.50: 電工神 (全問制覇) 👑
  - レベルアップ時のファンファーレ演出＆紙吹雪パーティクル！
- **ストリーク・コンボカウンター**: 連続正解で「🔥 3 連勝!」「🔥 5 連勝!」とコンボ倍率アップ
- **Web Audio API 効果音**:
  - 正解（明るい和音チャイム♪）
  - 不正解（低音ブザー）
  - コンボ（連続正解でピッチが上昇）
  - レベルアップ（アルペジオファンファーレ）
  - 音声ON/OFF切り替え対応
- **触覚フィードバック (Haptic)**: スマホのバイブレーション機能に対応
- **実績バッジ（10種類）**:
  - 「初電通」「電光石火」「3連続正解」「コンボマスター」「神ストリーク」「リベンジ達成」「計算の達人」「配線図マスター」「一人前電工」「全問完全マスター」

### 5. ⏱️ 本番模擬試験モード
- 制限時間120分のカウントダウンタイマー
- 本番同様に全50問を通しでマークシート解答
- 試験終了後に自動採点（100点満点中60点以上で合格判定発表！）
- 間違えた問題の一括リストからワンタップで弱点特訓へ移行可能

### 6. 📖 問題一覧＆用語辞書
- 全50問をいつでも一覧閲覧可能
- カテゴリ別（電気理論、配線機器、材料工具、施工法令、配線図）＆キーワード検索

## 🛠️ 起動・利用方法

### ローカル起動
```bash
npm run dev -- --host 0.0.0.0 --port 5173
```

### ブラウザでのアクセス
- **Mac / PC**: [http://localhost:5173/](http://localhost:5173/)
- **スマートフォン**: 同じWi-Fiに接続した状態で、ターミナルに表示されたローカルIPアドレス（例: `http://192.168.11.2:5173/`）をスマホのSafariやChromeで開きます。
- **ホーム画面に追加 (PWA風)**: スマホのブラウザの「ホーム画面に追加」をタップすると、アプリのように全画面で起動できます！
