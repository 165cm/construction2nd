# 有料化の実装方針案（2026-10-15）

ユーザー指定：最新版の過去問は無料、それ以前は有料。月額480円と自動更新なし3か月980円。980円を主に案内する。
準備状況：Stripeアカウントあり、独自ドメインなし、Supabaseアカウントあり。Firebaseを候補として検討中。料金は税込表示を想定し、公開前に運営者が確定する。

## 料金と導線

| プラン | 支払い | 利用範囲 |
|---|---|---|
| 無料 | 0円・登録不要で開始 | 最新1回50問の問題・解説・模試 |
| 3か月集中パック（主表示） | 980円一括、自動更新なし | 過去分も含む全収録問題・復習・模試 |
| 月額 | 480円、毎月自動更新 | パックと同じ学習機能 |

- 月額3回1,440円に対して460円安い。ただし2回なら960円なので「常に一番安い」とは書かない。
- パックは支払確認時点から暦の3か月（存在しない日付は月末へ補正）を案とする。サーバーで期限を計算し終了日時を表示。90日と混同しない。
- 初版では有効な契約の重複購入を防ぐ。月額からパックへの切替は、解約予約→満了後購入を明示。将来の差額変更は別設計。
- 月額は解約しても支払済期間の終了まで利用可。期限後も学習履歴は保持、最新無料分を続けられる。
- 無料学習10問終了・無料模試結果・過去年度選択のタイミングで案内。架空の人気順位や期限カウントダウンは使わない。
- 「合格保証」「合格確率」は根拠なく表示しない。

## 推奨候補：Firebase + Stripe

Firebase Authentication（ログイン）、Firestore（学習記録）、Cloud Functions等（決済確認・利用権判定）、Firebase Hosting（公開先）を候補とする。Google Cloudへ運営費を集約したい意図に合う。Stripeの決済費用までGoogleの請求になるわけではない。Google Payの導入自体はFirebaseを必要としない。SupabaseにもGoogleログインがあり、それだけが理由なら移行の必要はない。

独自ドメインは開発開始の必須条件ではない。テスト用URLで準備し、公開前にドメインと運営者情報を確定する。既存Cloudflareの問い合わせ受付は新しい公開先の許可設定も更新する。Firebaseの有料サービスには請求設定が必要で、費用予算・通知を設定する。アカウント所有だけでプロジェクト設定済みとはみなさない。

## 実装の境界

1. ゲストの最新50問はすぐ使える。購入時にログイン。既存端末記録の引継ぎは明示し、既存クラウド記録を無条件に上書きしない。
2. サーバーはログイン利用者と固定の料金ID一覧からCheckoutを作る。月額はsubscription、一括はpayment。ブラウザが送る金額を信用しない。
3. Stripe署名検証済みWebhookと支払状況から利用権を更新。成功画面への帰還だけでは解放しない。イベント重複・順序逆転・遅延を処理し、再実行で期間が延びないようにする。
4. 月額は支払済期間まで、一括は固定終了日時まで。解約予約・失敗・返金・取り消しを個別の契約へ反映する。別の有効契約を誤って無効にしない。
5. 有料問題本文・解答・解説・原本画像は公開バンドルから分離し、サーバーが毎回利用権を検証。Firestoreの利用権はクライアント書込禁止。学習履歴は本人だけに制限。
6. 認証・利用権・有料データAPIはService WorkerとHTTPキャッシュの対象外。初版の有料範囲はオンライン必須。公開済のGit履歴や既存キャッシュのコピー回収は保証できない。
7. 模試結果・学習履歴を保存。保存中／保存済／失敗を区別。通信断の再送に識別子を付けて二重記録を防ぐ。ログアウトと別アカウントへの切替で記録を混ぜない。
8. 秘密鍵はサーバーの秘密設定に置き、フロントのVITE変数・リポジトリ・チャットへ出さない。

## 公開前の確認

- 無料全50問、未ログインの有料アクセス拒否、URL直アクセス拒否、他人の記録拒否。
- 月額／一括の成功・失敗・中断、Webhook遅延・重複・順不同、二重クリック、二重契約防止。
- 解約・月末・期限直前直後・端末時計変更・返金・再購入。
- 既存端末データ移行、端末間同期、保存失敗、模試再読込、アカウント切替、ログアウト。
- 旧Service Workerからの更新、期限切れ時のキャッシュ、ネット切断の案内。
- 特商法表示、契約期間・総額・自動更新・解約・返金条件を購入確認画面に明示。運営者情報を推測して埋めない。

## 実施順と評価

1. 今回の不具合修正を公開。2. 学習中心のUI・模試結果保存・保存失敗表示。3. Firebaseプロジェクトとログイン／同期。4. Stripeテスト環境で2プランと有料配信。5. 契約表示・本番設定を確認し公開承認を得る。

無料開始→10問終了→無料模試→料金表示→購入開始→サーバー確認済購入を測定。返金・翌週の復習・模試得点も見る。980円の前払いは期間と費用が分かりやすいが、売上最大化は実データで検証する。低単価なので広告を大きく買う前に無料問題と説明ページからの集客を検証する。
