# 有料データの分離・配信準備

2026-10-16。**移行準備用。課金・本番配信はまだ開始しない。**

## 生成物

`npm run build:private-staging` は次の2つを生成する。

- `functions/private-content/`：共有修正を反映済みの過去200問（年度ごとJSON）と画像。配信できるファイル名を `manifest.json` で限定。Git対象外。
- `dist-private-site/`：最新50問だけを組み込む公開側の検証用出力。過去200問の元JSON、共有修正、選択肢設定、切り抜き設定を除去し、古い年度の画像フォルダをコピーしない。

通常の `npm run build` と現行の公開設定は維持する。**検証用出力はまだ本番へデプロイしない。** アプリ側の年度選択・取得・画像表示の接続が未対応のため、過去年を選んでも学習できない。これは課金対応の完成版ではない。

生成物は元ファイルから再作成する。元の教材・画像・共有修正を削除しない。元データとGit履歴はこれまでどおり公開リポジトリに残るため、コピー回収を保証する仕組みではない。

## 配信API

`privateContent` は `PRIVATE_CONTENT_ENABLED=false` が既定。GETのみ。Firebase Hostingから同じドメインの `/api/content` へ振り分ける構成を想定（Hosting設定は後続）。

- `Authorization: Bearer <Firebase ID token>` を要求。URLにトークンを含めない。
- Firebase側でトークンと失効を検証し、その本人の利用権をサーバー時計で確認。
- `exam=r7_2` のような許可済み年度で問題JSONを返す。
- 画像は同じ年度に属する `asset=pages/r7_2/page_15.webp` 等を指定。許可パターンとmanifestの両方を満たすファイルだけ返す。
- すべての応答は `private, no-store`。無認証401、利用権なし403、未知のパス404、設定無効/取得失敗503。
- Service Workerは認証ヘッダー付き、`/api/`、別ドメインの通信を処理しない。`private` / `no-store` 応答も保存しない。キャッシュ版をv3へ更新。

## テスト

`npm --prefix functions test` で価格・利用期限に加え、不正パス・未認証・失効・返金・取得失敗でデータを読まないことを確認する。外部接続は模擬で、本番FirebaseやStripeには接続しない。

`npm run test:private-staging` で200問の生成、公開JSへの固有問題文の混入、古い年度画像の公開出力除外、最新問題の保持、Service Workerの認証/API通信除外を確認する。共通の問題文・汎用早見表は有料データの漏出とは判定しない。

## 次に接続する部分

1. 認証済み利用者での取得、年度ごとの問題と画像のメモリ管理。
2. 通常・全年度復習・模試・問題一覧の無料/有料範囲と案内。未取得年度へ空の問題配列で入らないようにする。
3. 期限到達・ログアウト・利用者切替時に保持中データを破棄。画像もBlob URL等を破棄し、端末保存や共有キャッシュへ入れない。
4. 模試履歴に保存済みの有料問題本文をどう扱うかを移行設計（現行は本文ごと保存する）。
5. Firebase Hostingの振分け・本番ルール・実アカウントで期限切れ/画像直アクセス/旧キャッシュ更新を検証。

以上が完了するまで `PRIVATE_CONTENT_ENABLED` と `BILLING_ENABLED`、画面の `VITE_BILLING_READY` を有効にしない。

## 学習画面への接続（①）

検証用ビルドのみ `VITE_PRIVATE_CONTENT=true` を埋め込む。最新50問から開始し、有料年度は認証付きAPIの成功後に切替。本文・画像・切り抜き座標はメモリに保持し、画像取得は最大4並行。失敗した年度は表示しない。全年度復習には明示的な読込ボタンを用意。通常の無料版ビルドは維持する。②期限/ログアウト破棄、③保存履歴移行を完了するまで本番公開不可。APIは未デプロイで、購入済み実アカウントの結合テストは未実施。
