# 何を作っているか（PRODUCT）

## ひとことで
第二種電気工事士の過去問（令和6年度上期から令和8年度上期の5回・250問）をスマートフォンで片手親指でサクサク解き、間違えた問題を効率的に復習しながら、今日の学習量・弱点・模試結果を確認できるWebアプリ。

## 中心の使い方
1. **通常サクサクモード**: 1問1答で即時正誤判定＆図面・解説を確認しながら進める
2. **弱点特訓モード**: 間違えた問題・未マスター問題を抽出し、2回連続正解で記録上の「マスター」へ分類
3. **本番模擬試験モード**: 制限時間120分で50問を通しで解き、目標点の判定（60点以上）
4. **問題一覧・辞書**: 分野別・キーワードでいつでも問題文を検索（要点は解答後に確認）

## 強み
- **スマホ最適化UI**: 親指一本で解ける大きな四肢択一ボタン、片手操作対応
- **配線図（15頁）ワンタップビューア**: Q31〜50で図面・分電盤図を即座にポップアップ＆ピンチ拡大表示
- **学習量と弱点の確認**: 今日の解答数、年度別・分野別の記録から次に復習する範囲を確認
- **落ち着いた解答画面**: 解説を中心に表示。効果音は任意、振動・紙吹雪は使わない
- **完全ローカル動作・自動保存**: LocalStorageによる進捗・EXP・バッジの永続化

## 現行無料版で対象外としていたもの
- ユーザー登録・ログイン（手軽にすぐ始められるようLocalStorageで完結）
- サーバーサイドDB（完全クライアントサイド動作で高速レスポンスを維持）
