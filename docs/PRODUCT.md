# 何を作っているか（PRODUCT）

## ひとことで
第二種電気工事士の過去問（令和8年度上期・全50問）をスマートフォンで片手親指でサクサク解き、間違えた問題を効率的に復習しながら、全問制覇までの残りプレイ時間の推計とゲーミフィケーションで楽しく完全合格を目指せるWebアプリ。

## 中心の使い方
1. **通常サクサクモード**: 1問1答で即時正誤判定＆図面・解説を確認しながら進める
2. **弱点特訓モード**: 間違えた問題・未マスター問題を抽出し、2回連続正解で「完全マスター」へ昇格
3. **本番模擬試験モード**: 制限時間120分で50問を通しで解き、合否判定（60点以上で合格）
4. **問題一覧・辞書**: 分野別・キーワードでいつでも全問と重要暗記ポイントを検索

## 強み
- **スマホ最適化UI**: 親指一本で解ける大きな四肢択一ボタン、片手操作対応
- **配線図（15頁）ワンタップビューア**: Q31〜50で図面・分電盤図を即座にポップアップ＆ピンチ拡大表示
- **残りプレイ時間見積もり**: ユーザーの実際の解答ペース（秒/問）から「全問制覇まであと○分○秒」をリアルタイム算出
- **ゼロレイテンシ効果音＆バイブレーション**: Web Audio APIによる正解・不正解・コンボ・レベルアップファンファーレ
- **完全ローカル動作・自動保存**: LocalStorageによる進捗・EXP・バッジの永続化

## やらないこと（追いかけない）
- ユーザー登録・ログイン（手軽にすぐ始められるようLocalStorageで完結）
- サーバーサイドDB（完全クライアントサイド動作で高速レスポンスを維持）
