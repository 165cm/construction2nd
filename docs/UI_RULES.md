## 1. 文字は最小限

- 伝えるべきことは伝え、くり返しと毎回の説明は削る
- 毎回読まなくていい説明は ⓘ（押すと出る吹き出し）に入れる
- 意味が伝わるところは、絵文字＋短い言葉
- 押した結果は、押した場所の近くで返す。取り消せる操作には「↩ 元に戻す」

## 2. スマホ1画面の密度

- スマホが基本（縦 390×844 で確認）。横持ち・パソコンでも崩れないこと
- 主な操作のボタンは押せる大きさ（高さ44px以上）
- 1画面に主な目的は1つ

## 4. 解答前に答えを教えない（2026-10-14）

- 問題文と選択肢は原本の条件を守り、器具名・図記号の意味・読み取り結果を補足しない。
- 図・写真を鑑別する四肢は原本画像で表示し、ボタンは「図のイ」等とする。alt・title・一覧のプレビューにも解答を入れない。
- 解説・要点・関連早見表は解答後に表示。問題一覧は問題文・番号・大分類で検索する。
- 初期設定の自動送りはオフ。既存の設定は保持する。「マスター」は2回連続正解という記録上の基準で、長期定着や合格の保証ではない。
- 公式の共通条件は折りたたみ表示。法令の要点では適用条件を省いて一般化しない。
