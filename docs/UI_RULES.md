# 画面のルール（UI_RULES）

## 1. 文字は最小限

- 伝えるべきことは伝え、くり返しと毎回の説明は削る
- 毎回読まなくていい説明は ⓘ（押すと出る吹き出し）に入れる
- 意味が伝わるところは、絵文字＋短い言葉
- 押した結果は、押した場所の近くで返す。取り消せる操作には「↩ 元に戻す」

## 2. スマホ1画面の密度

- スマホが基本（縦 390×844 で確認）。横持ち・パソコンでも崩れないこと
- 設定画面はブラウザの実際に見えている領域（VisualViewport、未対応時はウィンドウ寸法）に高さ・位置を合わせる。見出し・閉じるボタン・タブはスクロールさせず、本文だけをスクロールする。ブラウザのバーや画面回転で表示領域が変わっても追従し、セーフエリアに余白を確保する。
- 主な操作のボタンは押せる大きさ（高さ44px以上）
- 1画面に主な目的は1つ

## 4. 解答前に答えを教えない（2026-10-14）

- 問題文と選択肢は原本の条件を守り、器具名・図記号の意味・読み取り結果を補足しない。
- 図・写真を鑑別する四肢は原本画像で表示し、ボタンは「図のイ」等とする。alt・title・一覧のプレビューにも解答を入れない。
- 解説・要点・関連早見表は解答後に表示。問題一覧は問題文・番号・大分類で検索する。
- 初期設定の自動送りはオフ。既存の設定は保持する。「マスター」は2回連続正解という記録上の基準で、長期定着や合格の保証ではない。
- 公式の共通条件は折りたたみ表示。法令の要点では適用条件を省いて一般化しない。

- 原本選択肢と同じ旧画像は二重表示しない。別の回路図・配線図は保持する。採点後も原本選択肢を見直せること。
- ページの拡大操作を禁止しない。

## 学習に集中する表示（2026-10-15）

- ヘッダーは年度・今日解いた数・記録設定・音声設定。レベル・EXP・連勝・完了までの推計時間を表示しない。
- 今日10問を目安として案内し、復習へ移れる。学習回数の強制や合格の保証には使わない。
- 正誤は解説と同じ場所に表示。自動送りオフなら重複ポップアップを出さない。既存の自動送り設定は保持。
- 紙吹雪・レベルアップ割込み・振動を停止。音は新規利用時オフ、保存済設定は保持。
- 速度・連続正解への加点を停止。過去のEXP・バッジなど保存済データは消さない。

## 設定と保存の補足（2026-10-19）

- 「Googleでログイン」は毎回Googleのアカウント選択画面を要求し、前回のアカウントへの自動ログインで別アカウントを選べなくしない。
- 一度読めば十分な補足は `HelpTip` のⓘからタップ/キーボードで開閉する。ホバー必須にしない。Escで閉じられる。
- 上書きの対象・料金・更新条件・エラーは操作時に直接表示する。
- 保存/復元の確認・処理中・完了表示は保存ボタンの直下に置き、料金欄を挟まない。初回保存は「保存する」、既存記録は「上書き保存する」と区別する。

- 決済状態の再確認ボタンは料金欄の上に置き、処理中・結果・テスト環境の案内を直下に集約する。初回の未購入を失敗扱いにせず、購入可能ならプラン選択へ案内する。

## 有料機能の入口（2026-10-20）
- 新規購入を停止しても、ログイン済み利用者の契約管理・月額解約の入口は購入可否と独立して維持する。サーバーの本人/顧客確認は省略しない。
- 再読み込み時は直前に使用していた年度を開く。有料年度は初期ログイン状態の復元とサーバーの利用権確認・教材取得を待ってから、その年度の保存済み学習位置を復元する。待機中は無料の最新問題へ進める。
- 失効・通信失敗などによる自動退避では、最後に選んだ年度の記憶を上書きしない。利用不可なら案内を表示し、利用者が明示的に無料年度へ切り替えた場合はその選択を記憶する。
- 年度一覧に「無料」「🔒 有料プラン対象」を表示する。
- 未認証・利用権なしの取得拒否は画面内の案内を出し、対象年度・無料範囲・価格・自動更新の有無を説明する。選択失敗だけでは年度を切り替えない。
- プラン/ログイン・無料問題・閉じるを選べる。購入済みの利用者へ再購入を促さず、ログイン/利用期限確認へ案内する。
- 通信失敗等は料金訴求から分け、再試行を主操作にする。
- 「全年度まとめて」は必要な教材が未取得なら読み込み・権限確認を経由する。無料年度だけで全年度と表示しない。
- 有料教材が期限・非表示等で破棄された場合は安全のため無料年度へ退避するが、再取得の案内画面を必ず表示する。

- 有料画像は必要なものから表示する。画像の通信中と再試行は画像の場所に表示。年度全体の画像ダウンロードを学習開始の前提にしない。原本ページはその場で開閉する。

## 問い合わせ（2026-10-21）

- ログイン前から学習画面・設定の「お問い合わせ（別タブ）」で窓口を開ける。学習画面を置き換えず、明示的な別タブ表記とnoopener/noreferrerを付ける。
- 公開問い合わせページは外部のスクリプトや認証に依存せず、宛先をコピーできるようにする。メールリンクは自動送信しない。
- 「異議あり」は一般問い合わせに流用しない。未確定の販売者情報や返金条件は仮の値で公開しない。
