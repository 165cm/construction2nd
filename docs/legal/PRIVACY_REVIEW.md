### 3. 端末保存とクラウド保存

学習記録や設定等をブラウザの保存領域に保持します。端末内の記録は、利用者がブラウザデータを削除すると失われる場合があります。

クラウド保存を利用する場合、Googleログイン後に「この端末の記録を保存」を押すと、記録をFirestoreへ送信します。ログインだけで学習記録を自動送信するものではありません。ログアウトでは端末記録や保存済みクラウド記録を削除しません。

### 4. 外部サービス

| 送信先・サービス | 本サービスでの用途 |
|---|---|
| Google/Firebase/Google Cloud | 認証、ホスティング、学習記録/利用権の保存、教材配信、障害ログ/監視 |
| Stripe | 支払情報の入力、決済、契約管理、支払い/返金の通知 |
| Google Groups（個人向け無料版）・Gmail | サポート窓口でのメール受信・対応履歴管理 |
| Cloudflare/Turnstile | 教材報告と問題情報の受付、ロボット対策。IPをTurnstile検証APIへ送信 |
| GitHub | 報告コメント、年度/番号/分類、問題文・選択肢・正解をIssueへ登録・管理 |

カード情報はStripeの画面へ入力します。アプリの入力欄にカード番号を保存する実装はありません。

GoogleログインにはFirebase Authenticationを利用し、認証に関するデータは同サービスの仕様により米国で処理されます。学習記録のFirestoreとFunctionsは東京の設定を使用していますが、認証・サイト配信・ログ等を含むすべての情報が日本国内だけで処理・保存されるものではありません。

「異議あり」の報告は、公開リポジトリで管理する間は内容が公開されます。氏名・メール・決済情報などを記入しないでください。支払いや個人情報に関する相談はサポート窓口へ送ってください。

### 5. 保存期間と削除

学習記録の削除依頼はサポート窓口で受け付け、本人確認後30日以内を目標に対応します。保存の必要性を6か月ごとに見直します。不要と分かった情報は次の点検を待たず削除対応します。請求処理・法令等により保存が必要な情報は学習記録と区別して扱います。

2026年10月22日時点のCloud Logging設定では、通常ログのバケットは30日、一部の必須監査ログのバケットは400日保持します。これは当該バケットの保持設定であり、外部サービスが独自に保持する認証・配信等の情報や、別に保存された調査記録を一律に含むものではありません。

通常の問い合わせ履歴は、対応完了後の再問い合わせに対応するため最長1年保存し、不要になったものは早めに削除します。未解決の請求・紛争や法令上保存が必要な記録は通常履歴と区別します。

学習記録の削除とは別に、決済・請求・返金・法令対応等のため必要な記録を、目的と適用法令に応じて必要な期間保存します。保存が必要な情報と理由を区別し、不要となった情報は削除対応します。

有料プランの解約は、アカウントや記録の削除とは異なります。アカウントの削除を希望する場合の契約停止・残期間の扱いは、利用者に説明して確認します。

### 6. 安全管理と本人からの請求

認証とアクセス制御により、本人のクラウド記録と利用権を区別して管理しています。運営権限・外部サービス等も含め、情報の漏えい等を防ぐための管理を行います。Google・GitHub・Stripeの運営アカウントには2段階認証またはパスキーを使用し、サポートグループの問い合わせ履歴を閲覧するメンバーは運営者本人だけに限定しています。

利用目的の通知、情報の開示・訂正・利用停止・削除等に関する請求・相談は、サポート窓口で受け付けます。本人確認のうえ法令に従って無料で対応し、対応できない場合には理由を説明します。

### 7. 改定

利用目的等の変更は適用法令に従い、必要な説明・同意手続きを行います。重要な規約変更に当たる場合は利用規約の原則30日前のサイト告知方針も適用します。プライバシー上必要な手続きをこの告知だけで代替しません。施行日・改定履歴は公開前に確定します。
